# English Dojo

A personal English learning project built for steady practice, review, and improvement.

English Dojo is one of my active learning repositories. It is designed as a practical place to organize English study, reinforce habits, and improve over time through focused practice.

## Purpose

- Build a consistent English study workflow
- Organize learning materials in one place
- Support review, repetition, and long-term progress
- Turn English practice into a maintainable daily system

## Learning Focus

- Reading
- Vocabulary
- Writing practice
- Structured review
- Personal study organization

## Project Direction

This repository is meant to grow with actual use.
The exact content and structure may change as better learning methods, materials, and practice routines are added.

## Current Status

This project is actively used and continues to develop over time.

## Notes

English Dojo is not intended to be a polished public course platform.
It is a practical working repository for personal English learning and iterative improvement.
